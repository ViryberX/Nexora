# NEXORA AI — Frontend & Design System Showcase

Nexora AI is a modern, high-performance web interface for an autonomous AI research platform. It combines deep web research syntheses, citations, interactive follow-ups, and export tools with a sleek glassmorphism aesthetic.

> **Note**: This repository serves as the public frontend showcase and UI portfolio. Proprietary backend AI workflows, search provider connectors, and serverless execution layers are securely hosted in private infrastructure.

---

## ✨ Features & Highlights

- **Modern Glassmorphic Workspace**: Built with responsive layouts, dark mode typography (Outfit + Inter), and micro-animations.
- **Deep Web Research UI**: Interactive citation blocks, progressive loading states, and dynamic report generation.
- **YouTube Video Summary Views**: Rich summaries, timeline chapters, and actionable takeaway breakdowns.
- **Export & Sharing Suite**: One-click PDF generation, markdown copying, and saved research sessions.
- **Admin & Usage Dashboard**: Metrics visualization, token counters, and system health status monitor.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Styling**: Bespoke Vanilla CSS with design token variables (no bloated third-party frameworks)
- **Tooling**: TypeScript, Oxlint

## 🚀 Local Development

1. **Clone the repository**:
   ```bash
   git clone https://github.com/viryber-hue/Nexora.git
   cd Nexora
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the local dev server**:
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Production Build**:
   ```bash
   npm run build
   ```
